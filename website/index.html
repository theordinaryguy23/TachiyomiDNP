✦ How It Works

Start Reading in 3 Steps

Getting started with TachiyomiDNP is quick and easy.

1

Download & Install

Download the APK from GitHub releases and install it on your Android device. Enable "Install from unknown sources" if needed.

2

Add Extensions

Browse and install extensions for your favorite manga sources. The default repo (keiyoushi) is pre-configured — extensions work on first launch.

3

Start Reading

Search for manga, add them to your library, and start reading. Download chapters for offline reading anytime.
